# 🕌 Belajar Ngaji Anak

Website pembelajaran Al-Qur'an interaktif untuk anak-anak dan pemula dengan tampilan modern, responsive, dan mudah digunakan.

## ✨ Features

* 🔐 Login & Register Authentication
* 📖 Belajar Huruf Hijaiyah
* 🔊 Audio Interaktif
* 📚 Iqra Interaktif
* 🎨 Modern Islamic Landing Page
* 📱 Responsive Design
* ☁️ Deploy menggunakan Vercel

---

## 🚀 Demo Website

🌐 https://belajar-ngaji-anak.vercel.app

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Firebase Authentication
* Materialize CSS
